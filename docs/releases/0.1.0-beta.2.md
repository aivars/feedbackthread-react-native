# 0.1.0-beta.2 — Service settings compatibility

Adds `client.conversationSettings()` to read typed project reply, notification
and public-comment policy. Existing board, feedback, voting and shipped-update
behavior is unchanged. The development/example Expo patch is now 57.0.21.

```sh
npm install https://github.com/aivars/feedbackthread-react-native/releases/download/0.1.0-beta.2/feedbackthread-react-native-0.1.0-beta.2.tgz
```

This is an opt-in GitHub beta, not an npm-registry or stable release. Secure
customer sessions, conversation/comment UI and native push delivery are not
included. A service flag does not establish device permission or SDK support.
Full conversation integration is currently available in Swift 0.5.0.

Validation: 18 client tests, 7 component tests, build/typecheck, the local real
Worker contract, packaged-example typecheck, Expo dependency compatibility and
iOS/Android production bundle exports. See [the beta checklist](../BETA-TESTING.md)
for unchanged device-testing limitations.
